AudiQ V2
Audiogram photograph → threshold candidates → clinician verification → clinical analysis → report

1. Capture or upload the audiogram

Use a clear, front-facing photograph with the complete audiogram chart visible. V2 performs browser-side colour/symbol extraction. It is an experimental aid, not validated OCR.

2. Automatic extraction

The analyzer looks for common red/blue audiogram marks, estimates the six frequency columns and maps vertical position to dB HL using the detected chart area. Because audiogram layouts vary, the result must be checked.

3. Detected thresholds

Red is treated as a candidate right-ear series and blue as a candidate left-ear series. These defaults can be changed before verification.
