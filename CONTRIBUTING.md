# Contributing to AudiQ

Keep AudiQ focused on behavioral audiometry education and supervised clinical training.

- Do not commit identifiable patient data.
- Preserve the manual verification gate for image-extracted thresholds.
- Preserve masking decision-support warnings and clinical review requirements.
- Add tests for calculation or workflow changes.
- Document changes to clinical assumptions, references, and validation status.

Run:

```bash
npm test
```

Software tests demonstrate software behavior; they do not establish clinical validity.
