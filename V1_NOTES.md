# AudiQ v1

AudiQ v1 is an educational and clinical-documentation prototype for audiometry workflow support.

- PTA calculation
- AC thresholds
- shared/non-ear-specific BC workflow
- masking decision support
- speech audiometry documentation
- audiogram visualization
- printable report
- privacy and consent guidance
- experimental audiogram photo analysis

Verify all outputs before clinical use. Do not place identifiable patient data in this public repository.
