# AudiQ AI — Data Sources & Licensing Log

This file is the audit trail for datasets used by AudiQ AI.

## Rules

- Do not commit patient images or identifiable clinical records to this public repository.
- Record the source, access date, license/permission, and allowed use before importing a dataset.
- Dataset rights are separate from software/code licenses.
- If a dataset is restricted, keep it outside the repository and document its access conditions.
- Synthetic data generated by AudiQ's own script is self-contained and may be used for pipeline development.
- A dataset must not be described as a clinical validation set unless it has been independently designed and evaluated for that purpose.

## Planned additions

Before adding any real dataset, record:

1. Dataset name and URL
2. Version/date accessed
3. Number of images
4. Annotation format
5. License or written permission
6. Commercial-use status
7. Whether redistribution is allowed
8. Whether derived model weights may be redistributed
9. Any required citation
10. Where the dataset is stored locally/Kaggle

## AudiQ held-out test set

The seed/teacher-verified test images must remain outside training and validation. Their source and permission status must be documented before use.
