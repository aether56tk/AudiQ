# AudiQ Validation Status

## Implemented

- Audiogram-photo candidate extraction workflow
- Manual threshold verification gate
- PTA calculation
- Audiogram pattern/configuration workflow
- Masking decision-support screen
- Reporting and print workflow
- Privacy/safety boundaries
- Automated deployment

## Pending

**Clinical/research validation remains the only unfinished research step.**

Required evidence includes a governed de-identified audiogram image set, expert reference thresholds, frozen software version, extraction-error analysis, failure-case review, and protocol-based review of masking guidance.

No diagnostic accuracy, OCR accuracy, or clinical-performance claim should be made before that work is completed.
